### 📥 Installation

**Option 1: Just want to use the app (recommended):**

1. Download `GiffyPy.zip` from the assets below and extract it.
2. Open `GiffyPy.exe`.
3. Optionally, run the included `create_shortcut.bat` to add GiffyPy to your Start Menu.

**Option 2: Build it yourself from source:**

1. Download `Source code.zip` from the assets below and extract it.
2. Double-click `build.bat`. It installs everything needed (asking for permission for each dependency) and builds the app for you.
